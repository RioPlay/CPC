# CPC Governance

## Project stewardship

CPC — Compact Project Capsule — was created by **RioPlay**.

RioPlay is the sole maintainer and final authority for the official CPC specification, wire-format evolution, reference implementation, roadmap, and releases.

## Contributions

The official CPC repository does not currently accept external code contributions.

Bug reports, interoperability results, test cases, issue reports, and feature suggestions are welcome.

Forks and derivative works are permitted under the MIT License. They remain independent derivative projects unless RioPlay explicitly adopts changes into the official CPC project.

## Official project

Only releases published or approved by RioPlay are considered official CPC releases.
